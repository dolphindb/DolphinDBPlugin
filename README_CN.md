# DolphinDB Plugin

DolphinDB 支持动态载入外部插件，以拓展系统功能。插件仅支持使用C++编写，并且需要编译成so共享库或者dll共享库文件。

插件开发可以参考以下文档： [插件开发指南](https://marketplace.dolphindb.cn/developer-helper)，[插件介绍与使用](https://docs.dolphindb.cn/zh/plugins/plg_howtos.html)，[插件开发教程](https://docs.dolphindb.cn/zh/plugins/plg_dev_tutorial.html)，[插件开发深度解析](https://docs.dolphindb.cn/zh/plugins/plg_dev_tutorial.html)。
